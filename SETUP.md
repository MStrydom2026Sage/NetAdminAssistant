# Installation

1. Open `chrome://extensions/` in Chrome and enable Developer mode.
2. Choose **Load unpacked** and select the `extension` directory.
3. Navigate to a NetAdmin ticket and use the floating green button, popup, or side panel.

The Offline rules engine runs in the extension. No localhost service, API key, or npm installation is needed. Optional Sage resource links open external sites only when clicked. Run `npm test` for local regression checks with Node 18+.
